# Voxel Rethinked | Minecraft Rethinked

Note! this is a fully educational project designed, and created for learning. I am not an expert! and the software is provided "as is".

---

# Project Details

>This minecraft clone is different from the standard minecraft game just by being developed in C++ and not Java.
>
> It uses OpenGL just like minecraft but in a more performative way, espesially in the lighting system, Chunk system, and world generation system for fast world load and generation aswell as chunk generation and to go beyond the limits of view distance with a custom LOD premapped world seed-gen way to load Many many chunks and aswell as low level of detail unloaded chunks. with a 16x16x16 chunk design rather than a 16x256x16.
